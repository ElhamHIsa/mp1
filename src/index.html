Research

  • Vanderbilt MIND Lab · 2025–present

    fMRI: recursive versus iterative coding

    Built the analysis pipelines for an fMRI study in which participants write recursive and iterative code inside the scanner, asking how the brain distinguishes these two modes of computation and how recursion in code relates to recursion in language. I develop the preprocessing and denoising pipeline and the keystroke-to-volume synchronization that aligns what participants typed, character by character, with the imaging timeseries. That alignment is what makes trial-level cognition separable in the signal.

    Python · FSL · FreeSurfer · MeshLab

  • UIUC Crowd Lab · Summer 2024

    Equivalent mutants and an 80% ceiling

    RIP classification models for telling equivalent mutants apart across 400 Java and Python pairs. Accuracy plateaued near 80%, so I wrote unit tests to establish ground truth on the disagreements and traced the ceiling to what the hypothesis class can represent.

    Java · Python · Mutation testing

  • Pioneer Research Institute · 2022

    How much does quantum actually threaten AES and DES?

    Authored a paper comparing the classical and quantum time complexities of brute-force attacks on DES and AES, showing how a uniform quadratic speedup affects them unevenly: it trivializes DES's 56-bit keys, weakens AES-128, and leaves AES-256 secure.

    Cryptography · Quantum computing
